Conclusão.

A análise integrada mostra que volume absoluto de UBS não é suficiente para interpretar presença territorial. São Paulo, por exemplo, aparece com alto número de unidades, mas sua razão por população é baixa em comparação com estados menores.

O dashboard agora funciona como uma camada de inteligência: identifica distribuição, compara proporcionalidade populacional, mede densidade territorial e sinaliza prioridades de investigação. A próxima etapa deve trazer a mesma lógica para o nível municipal.
