Project question

How can geographic and cadastral data from primary healthcare units be transformed into useful intelligence for territorial planning, BI dashboards and data quality monitoring?

47,714 UBS records 27 states 5,483 municipalities 95.96% valid coordinates

Executive snapshot.

The dataset has broad national coverage and is suitable for geographic portfolio presentation, but some coordinate quality issues must be documented before operational use.

Regional and state distribution.

Use the filters to move between national, regional and state-level views. The dashboard shows distribution of registered UBS records, not population-adjusted coverage.

Data quality signals.

Coordinate completeness is strong, but repeated coordinates and missing latitude/longitude should be treated as governance flags before using the base in operational dashboards.

What this means.

The analysis is useful for mapping, dashboard prototyping and data quality monitoring. Coverage conclusions require additional population and service production data.

01

Strong mapping base

Most records have usable coordinates, making the dataset ready for map-based exploration and geographic BI storytelling.

02

Distribution is not coverage

High counts do not mean adequate access. Population, demand, catchment area and production indicators are needed for coverage analysis.

03

Governance opportunity

Missing or repeated coordinates can be monitored as data quality KPIs in public health information systems.
