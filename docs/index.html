Meus trabalhos

Projetos construídos com problema, evidência e storytelling.

01

Health Analytics · Inteligência Territorial · BI em Saúde Pública

UBS + IBGE + Cobertura Potencial APS

Contexto: o planejamento da Atenção Primária não depende apenas de contar unidades. É preciso entender território, pressão populacional, capacidade instalada e qualidade dos dados.

Objetivo: integrar dados de UBS, indicadores territoriais do IBGE/SIDRA e Cobertura Potencial da APS para apoiar decisões de planejamento em saúde.

Resultados: 47.714 registros de UBS, 5.483 municípios e um painel que compara distribuição, cobertura, qualidade de coordenadas e pressão populacional.

  • 47.714 UBS
  • 5.483 municípios
  • 210,4M população APS

Ferramentas: Python · Pandas · IBGE/SIDRA · Data Quality · Dashboard

02

Machine Learning · Risco Clínico · Responsible ML

Heart Disease Risk Prediction

Contexto: bases clínicas podem apoiar a investigação de risco cardiovascular, mas boa performance estatística não significa prontidão clínica sem validação e governança.

Objetivo: avaliar modelos de classificação e traduzir variáveis técnicas para significado clínico, com limites claros de uso responsável.

Resultados: ROC-AUC próximo de 0,93, dicionário clínico, importância de variáveis e painel PT/EN para interpretação do modelo.

  • 918 registros
  • 11 preditores
  • ROC-AUC ≈ 0,93

Ferramentas: Python · Pandas · Scikit-learn · Machine Learning · Permutation Importance

03

Marketplace Analytics · SQL Mart · CX Risk · Storytelling

Olist Delivery Experience Analytics

Contexto: em marketplaces, a avaliação do cliente muitas vezes reflete o fim de uma cadeia operacional que envolve sellers, frete, distância, promessa de entrega e expectativa.

Objetivo: transformar os CSVs brutos da Olist em um mart analítico por pedido, testar hipóteses de negócio e criar um dashboard narrativo sobre risco de baixa avaliação.

Resultados: 99.441 pedidos, R$ 15,8M em GMV, camada de auditoria raw com Git LFS, transformação SQL e painel bilíngue inspirado na identidade visual da Olist.

  • 99.441 pedidos
  • R$ 15,8M GMV
  • PT/EN dashboard

Ferramentas: Python · Pandas · SQL · Git LFS · KaggleHub · Scikit-learn

04

Graph Analytics · Neural Search · Hybrid Recommender · NLP

CineGraph Network Intelligence

Contexto: dados de filmes, séries, pessoas, recomendações e reviews podem ser analisados como um grafo de conhecimento para apoiar descoberta de conteúdo e inteligência de catálogo.

Objetivo: construir uma versão prévia em Streamlit combinando graph analytics, busca semântica, recomendação híbrida e explicação de scores sobre a base CineGraph.

Resultados: app prévio com KPIs de catálogo, busca de filmes/séries, recomendador híbrido, exploração de rede pessoa-título, busca semântica e explicação das recomendações. Próximas melhorias: embeddings persistentes, FAISS, Node2Vec/GraphSAGE e camada RAG.

  • 22.393 filmes
  • 58.393 pessoas
  • Streamlit preview
  • Graph + Neural Search

Ferramentas: Python · Streamlit · Pandas · NetworkX · Scikit-learn · Sentence Transformers · KaggleHub
